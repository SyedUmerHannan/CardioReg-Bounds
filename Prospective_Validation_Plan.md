# Prospective validation plan

This is a research plan, not a registered preregistration and not evidence for either manuscript.

A convincing empirical validation would require:

1. An independently calibrated assay-signature model for the exact population, assay schedule, localization rules, and analysis pipeline used in validation.
2. Multiple biological challenge units so repeated coverage can be evaluated; cells or fields within an animal/batch are not independent challenge units.
3. A target, history partition, calibration file, and analysis script frozen before an independent lineage or cell-count endpoint is opened.
4. Animal/batch-level inference, explicit handling of unequal cell counts, and a stated policy for assays measured on the same versus different biological units.
5. Arm-specific signatures, or a prespecified sensitivity range, when treatment can alter marker duration, event timing, retention, or localization.
6. A withheld endpoint on a commensurate denominator and horizon. For net-gain targets, direct cardiomyocyte count/survival information is required in addition to endpoint composition.
7. Reporting of target lower and upper bounds, width, misses, infeasibility, and all post-lock model revisions.

Post-unblinding changes to the calibration model would define a new model version and require new validation data.
